# SportMeet

## 📝 Descripción del Proyecto

**SportMeet** es una aplicación diseñada para conectar a entusiastas del deporte dentro de la Universidad de Antioquia, permitiéndoles organizar, encontrar y unirse a eventos deportivos en su área. Ya sea que necesites completar tu equipo de fútbol, encontrar compañeros para un partido de baloncesto o programar una sesión de entrenamiento de running, SportMeet simplifica la coordinación deportiva.

---

## 🛠️ Tecnologías Utilizadas

Este proyecto fue construido utilizando una arquitectura moderna de *backend* y *frontend*.

### Backend (API)

| Tecnología | Descripción |
| :--- | :--- |
| **Node.js** | Entorno de ejecución de JavaScript. |
| **Express.js** | Framework web rápido y minimalista para Node.js. |

### Base de Datos
| Tecnología | Descripción |
| :--- | :--- |
| **PostgreSQL** | Base de datos relacional robusta y de código abierto (migración desde MySQL). |

### Frontend

| Tecnología | Descripción |
| :--- | :--- |
| **React** |	Librería principal para la construcción de interfaces de usuario.
| **Vite** |	Empaquetador y herramienta de desarrollo ultrarrápida.
| **TypeScript** |	Lenguaje de programación que añade tipado estático al código.
| **Shadcn UI / Radix UI** |Sistema de componentes sin estilos (headless) para accesibilidad y usabilidad.
| **Tailwind CSS** | 	Framework CSS utility-first para un desarrollo rápido de la interfaz.
